## API Reference

### Flower

A flat flower that fans its petals evenly around the center.
It mainly serves as the component documented by the landing page demos.

**Flower Props:**

| Prop   | Type          | Default    | Description                                                        |
| :----- | :------------ | :--------- | :----------------------------------------------------------------- |
| label  | `string`      | -          | Accessible name. The flower is treated as decorative when omitted. |
| color  | `FlowerColor` | `'purple'` | Petal color, taken from the Radix color scales.                    |
| petals | `number`      | `8`        | Number of petals fanned evenly around the center.                  |
| size   | `number`      | `160`      | Width and height of the flower in pixels.                          |
